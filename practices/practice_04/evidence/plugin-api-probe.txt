Выводы:

1. От [define] нет ни строки: import { Plugin } from "@opencode/plugin" в 2.0.15
   не резолвится. Виртуальным модулем бинарь отдаёт только @opencode/plugin/tui.
   Рабочая форма - плоский объект: export default { id, async setup(ctx) }.
2. Строка tool.execute.after (V1 API) в бинаре отсутствует вовсе, тогда как
   execute.after и execute.before есть. Документация на opencode.ai/docs/plugins
   описывает V1 и для 2.0.15 неприменима.
3. ctx.shell содержит только hook - запускать им команды нельзя, раннер
   вызывается через node:child_process.
4. ctx.location.directory - каталог практики, ctx.location.project.directory -
   корень git-репозитория. Путь до раннера поэтому вычисляется от самого файла
   плагина, а не от текущего каталога.
5. setup вызывается дважды за один запуск сервера, поэтому hook не копит
   состояние.
